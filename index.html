Holy Monitor

System sanctity monitor written in HolyC for Linux. Monitors selected applications and automatically enforces divine judgment when your sanctity drops to zero.

Installation

Clone the repository and run the installer script:

git clone https://github.com/ollipix/Holy-monitor.git cd Holy-monitor chmod +x install.sh ./install.sh

Once installed, run:

holy-monitor

HolyC

Holy Monitor is written in HolyC and is intended to run on Linux.

Inspired by TempleOS

Holy Monitor is inspired by TempleOS , the operating system created by Terry A. Davis.

Terry A. Davis

Terry A. Davis (1969–2018) was the creator of TempleOS and HolyC. His work and dedication to building an entire operating system from the ground up are a major inspiration for Holy Monitor.

This project is a small tribute to Terry's work, TempleOS, and the unique programming culture he created around it.

Rest in peace, Terry.
