
# Holy Monitor

System sanctity monitor written in HolyC for Linux. Monitors active system tasks for bloated Electron apps and spyware, automatically enforcing divine judgment when your sanctity drops to zero.

## Installation

Clone the repository and run the installer script:

```bash
git clone https://github.com/ollipix/holy-monitor.git
cd holy-monitor
chmod +x install.sh
./install.sh
```

## Manual Execution

If you prefer running directly with your Linux HolyC compiler:

```bash
holyc src/holymon.c
```
